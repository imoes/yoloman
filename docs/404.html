That page is not here — and if it used to be, this is what happened to it.

A thing that disappears without saying so leaves you unable to tell "it never existed" from "it was removed on purpose". Both are answers; a blank 404 is neither. So:

  • modules-windows.json and modules-linux.json were deleted on 2026-08-28. They were a JSON copy of the module references, on the theory that "machine-readable" means a schema dump. That was a misunderstanding of the machine reader: a model needs to know what a module is for, what it refuses, and which of two similar ones is right — {"type": "string"} answers none of those. The prose pages answer all three, and they are served here as plain markdown, which is the machine-readable form. Read modules-windows.md or modules-linux.md instead.
  • A .md link that looked broken may not be: this site serves markdown as raw text rather than rendering it. That is on purpose — it is the best format for a model fetching a page — but a human usually wants GitHub's rendered view.
  • Anything else was most likely never here. This site serves only the docs/ folder of the repository; the rest of it lives on GitHub.
